
# The 7 Project Questions

**1. What real problem does this solve?**
→ Be specific. What is currently difficult, slow, expensive, annoying, or impossible?

**2. Who exactly has this problem?**
→ Not "everyone" or "students." Name the actual person/user.

**3. How are they solving it right now?**
→ What's their current workaround? Manual work, Excel, WhatsApp, ChatGPT, another tool, etc.

**4. Why would they actually use my solution?**
→ What becomes **easier, faster, cheaper, better, or possible** because you built it?

**5. Would someone pay for this?** 💰
→ Who would pay, and **what value are they getting for their money?**

**6. Can I actually build a useful version with the time, skills, and resources I have?**
→ Don't design a NASA mission when you have a laptop and 2 weeks. 😭

**7. What will prove that this project is successful?**
→ Pick a concrete outcome: *10 users, ₹5,000 earned, 5 hours saved/week, 80% task accuracy, 3 paying customers,* etc.

### The whole thing in one line:

> **Problem → Person → Current solution → Your value → Money → Feasibility → Proof**

And honestly, **if you can't answer #1, #2, #4, and #5 clearly, don't start coding yet.**

Those four are the real gatekeepers. Everything else comes after.
